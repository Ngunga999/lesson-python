# Python Lessons

A collection of beginner Python exercises and examples, organized by lesson. The files cover core language concepts and build toward small interactive programs, including several versions of Rock, Paper, Scissors.

## What you'll find

- Strings, numbers, booleans, and type conversion
- Lists, tuples, dictionaries, and sets
- Loops, functions, recursion, and scope
- Closures
- Interactive input and a simple Rock, Paper, Scissors game

## Requirements

- Python 3
- No third-party packages are required for the current examples.

## Running an example

Open a terminal in the project folder and run a Python file directly. For example, in PowerShell:

```powershell
python hello.py
python "Lesson 5\rps.py"
python "lesson 4\data_types.py"
```

Some examples ask for input in the terminal. Run one file at a time; these are standalone lesson exercises rather than a single application. A few files may be works in progress, so an example may need fixes before it runs successfully.
